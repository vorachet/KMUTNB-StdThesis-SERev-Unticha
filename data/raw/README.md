# ข้อมูลดิบของโครงงานต้นทาง และการเทียบกับแบบจำลอง DSL

โฟลเดอร์นี้เก็บผลการศึกษาของโครงงานต้นทางสองเล่ม ซึ่งไม่ได้ผ่านการสร้างแบบจำลองวิศวกรรมระบบ (MBSE) เป็นไฟล์ CSV หนึ่งข้อเท็จจริงต่อหนึ่งแถว ทุกแถวบอกแหล่งที่มาถึงระดับหน้า ตาราง หรือสไลด์ และมีไฟล์เทียบสองไฟล์ที่วางตัวเลขในแบบจำลอง `DSL/DurianOrchardMonitoring` ไว้ข้างข้อมูลดิบ

## แหล่งข้อมูล

| รหัส | เอกสาร |
|---|---|
| P2 | Tuntawisut, Kurapa & Keeratipitayanusarn (2024) การพัฒนาเสาอินเทอร์เน็ตของสรรพสิ่งสำหรับการตรวจวัดและวิเคราะห์ข้อมูลในสวนผลไม้ |
| GUI | Nunthasrithananon, Suyawa & Bubpha (2024) การออกแบบและพัฒนาส่วนติดต่อผู้ใช้แบบกราฟิกสำหรับฟาร์มอัตโนมัติ (เล่ม docx) |
| GUIS | สไลด์สอบป้องกันของโครงงาน GUI (`R1/sw.pdf`) |
| TH | วิทยานิพนธ์ฉบับนี้ (`Thesis.md`) สำหรับค่าที่อ้างจากแหล่งซึ่งข้อความในไฟล์ต้นฉบับไม่แสดง |

`P3 (Durian).pdf` เป็นโครงงานเครื่องวัดความสุกของทุเรียน ไม่ใช่โครงงาน GUI จึงไม่ได้ใช้

## สิ่งที่การเทียบพบ

ตัวเลขใน DSL ไม่มีตัวใดเป็นค่าสันนิษฐาน ทุกตัวมาจาก P2, GUI, GUIS หรือวิทยานิพนธ์นี้ ส่วนที่ไม่ตรงกันอยู่ระหว่างข้อมูลดิบกับค่าที่เอกสารต้นฉบับสรุปไว้เอง

- พลังงานแบตเตอรี่ 31.7821 Wh คำนวณซ้ำจากบันทึก 101 แถวได้ตรงทุกหลัก แต่บันทึกยาว 16.67 ชั่วโมง ไม่ใช่ 16 ชั่วโมงที่รายงาน และกำลังเฉลี่ยของการทดสอบคือ 1.9081 W ไม่ใช่ 2.3772 W ที่วัดด้วยมัลติมิเตอร์
- RSSI เฉลี่ยของ 48 เฟรมที่รับได้ที่ 400 เมตรคือ -89.271 dBm ไม่ใช่ -84.16 dBm ที่เล่ม GUI ระบุ
- งบการเชื่อมโยงในเล่ม GUI หักอัตราขยายของเสาอากาศสองครั้ง ถ้านับครั้งเดียวได้ -50.6 dBm ไม่ใช่ -40.8 dBm
- รายการจัดซื้อของโครงงานเสารวมได้ 157,362 บาท ไม่ใช่ 156,858 บาทที่พิมพ์ไว้ และ 156,858 บาทเป็นยอดของโครงงานเสาโครงงานเดียว ไม่ใช่สองโครงงาน
- เสาทุกต้นที่ติดตั้งจริงอยู่ห่างจากเกตเวย์ไม่เกิน 60 เมตร ขณะที่ขอบเขตกำหนด 400 เมตร
- รอบรายงานทุก 4 ชั่วโมงและโควตา 300 ข้อความต่อเดือนมาจากการอ้างอิงในวิทยานิพนธ์นี้ ข้อความในเล่ม GUI ไม่แสดงตัวเลขทั้งสอง จึงยังไม่ได้ตรวจกับต้นฉบับ
